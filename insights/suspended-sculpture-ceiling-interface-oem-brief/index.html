Suspended Sculpture Fabrication for Hotel Atriums

Published November 16, 2026By WEIERYANGEnglish procurement guide
Direct answer

Once a hotel atrium will use suspended art, an OEM quotation needs a current ceiling plan and section, an identified set of hanging locations, and written responsibilities for building supports, lighting and access. Use a register with one line per visible drop or interface. Link each line to the drawing revision, who reviews it and what can proceed while details are open.

Give the design team and supplier the same drawing set

Send the current plan showing ceiling features, a section that establishes the intended lower edge of the artwork, and the approach views the hotel has approved. Label each file with its revision and date. On the art layout, give each element or group an ID. Note which views establish the arrangement and who can approve a visual change.

The fish-form production record shows illuminated outlines, hanging lines and their spacing. A buyer planning a similar grouped form can use the image to explain which parts should read together from the lobby floor and upper levels. The project's own drawings are needed to coordinate the building and artwork interfaces. If the team is still choosing between floor support and suspension, start with the hotel atrium planning guide.

See how a new ceiling revision changes the brief

Imagine the architect shifts a service access panel after the fish-shaped group has been approved visually. A visible drop shares the same ceiling zone as the newly positioned panel. Mark the affected drop as open in the register, link the revised drawing, and ask the design team, engineer and supplier to coordinate their respective interfaces. Then have the buyer check how the revised layout reads from the agreed viewpoints.

Record which parts can still be priced and which depend on that review. This gives competing quotes the same assumptions about art fabrication, site supports, lighting connections, access equipment and installation. The buyer can compare the proposed work and its exclusions line by line.

Send these details to start a project review

  • Artwork — Current layout, intended material or appearance, photos or models and preferred viewing angles.
  • Venue — Current ceiling plan, section, site photographs, project city and target installation window.
  • Responsibilities — Who is reviewing structure, power and local installation, along with unresolved items that affect the quotation.

Copy the open items into your brief and mark which information already has approval. For a wider breakdown of supply and site responsibilities, use the sculpture quote checklist.

Frequently asked questions

Can I ask for a suspended sculpture quote without a final ceiling plan?

Yes. Send the most recent plan and section with their revisions, the target dimensions and any open coordination questions. Ask the supplier to identify the assumptions that keep the quotation provisional and the drawings needed before release.

What is the difference between a visible drop and a building support point?

A visible drop describes where and how the hanging element appears in the room. A building support point must be located and reviewed by the responsible structural design team. Give each a reference in the same register so the agreed visual layout can be matched to the approved support information.

Who provides lighting and power for suspended artwork?

Confirm the scope with both the sculpture supplier and the building electrical team. Record which components are part of the artwork, where building power ends, who provides controls and who can access the equipment for service.

What should change if a ceiling drawing is revised?

Compare the new drawing and revision against the agreed layout. Identify the impacted items, recheck the visual and building interfaces with the responsible reviewers, and update the point register before affected items are released.
