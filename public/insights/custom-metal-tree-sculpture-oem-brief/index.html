Custom Metal Tree Sculpture OEM RFQ Checklist

Published November 9, 2026By WEIERYANGEnglish procurement guide
Direct answer

To request a custom metal tree sculpture quote, send a site plan and one approved or clearly marked preliminary drawing. Show the crown outline, trunk split, ground level and base location. Ask each bidder to identify which branches travel attached, which travel separately, and who checks the connections before shipping and after arrival.

Mark the silhouette and the arrival view

Give the supplier a front view aligned to the approach, a side view and a plan. Mark approximate overall height and crown span, the trunk position, and the side visitors see first. If the brief starts with a rendering, use callouts to identify the branches and openings that define the silhouette. The site team can then compare that envelope with the paths, planting and overhead features shown on its plan.

Ask both bidders to price from the same drawing revision. If one bidder proposes rotating a branch or moving a split to make packing easier, request a marked view showing what changes from the main approach. Have the design reviewer confirm the appearance and the project engineer review the connection and site implications.

Use the same part names from drawing to delivery

A buyer can ask for a part register before approving the quotation scope. Record a drawing revision, part ID and mating ID for each separate piece, then ask the supplier to carry those identifiers into the trial-fit record and crate inventory. For your own sculpture, agree which pieces the supplier will fit together for review and which photos or records will identify the mating parts. When the local installation team receives the crates, use the same IDs to check the shipment and route questions back to the correct drawing.

Prepare the files for a tree sculpture quote

  • Site city and country, installation target and whether the work is for a hotel arrival, resort garden or public landscape.
  • One marked approach view, approximate height and crown span, and a site plan or photos.
  • Available PDF or DWG drawings and the revision each bidder should use.
  • Preferred finish, any branch or joint that must stay visually clear, and the proposed base location.
  • Open questions about assembly, site access and responsibilities that should be priced separately.

Use the project description to list the decisions you still need help with. Attach the drawings or photos you already have.

Frequently asked questions

Can I get a metal tree sculpture quote from a rendering?

A rendering can start an indicative review. Include approximate height and crown span, the destination, a marked approach view and any available site dimensions. Ask the bidders to list the assumptions that will need confirmation before production.

How do I compare detachable branches with a crown assembled in the workshop?

Ask both bidders to show transport dimensions, joint locations, finish expectations, trial-fit evidence and the local assembly scope against the same drawing revision.

Who confirms the tree sculpture base and anchors?

Agree who designs and verifies the artwork support and the receiving foundation. Share the current site levels and interface drawings with the sculpture supplier and the responsible project engineer.

What should I ask for before the crates ship?

Agree the packing list, crate IDs, part register, assembly information and expected inspection records. Use matching identifiers on the parts, crates and drawings so the receiving team can confirm what arrived.
