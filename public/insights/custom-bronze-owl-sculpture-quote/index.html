How to Commission a Custom Bronze Owl Sculpture

Published November 28, 2026By WEIERYANG
What should an owl sculpture supplier quote?

Give the supplier the owl species, one pose you have permission to use, the bird’s height or wingspan and the delivery city. Show the perch and plinth separately. Ask each supplier to identify the casting material and to price the model, casting, finish and packing on separate lines.

Start with the owl a visitor should recognise

A barn owl perched above an interpretation sign presents a different outline from an owl landing beside a trail. In a perched pose, the face and the space between the feet and the branch can carry the design. In flight, the widest point may sit well above the base. A height on its own leaves most of that decision to the modeller.

Send an original or licensed wildlife reference. On a copy, draw an arrow for the visitor’s approach, circle the features that matter, and mark where the bird looks. Ask for front and side views of the proposed model before approving the silhouette.

Measure the bird, the perch and the space around them

Record dimensions in one unit. If a measurement is open, label it as a supplier proposal so you can see how each bidder interpreted the drawing.

BirdHeight from feet to crown or maximum tip-to-tip spanSets the size of the model
Perch and baseBranch projection and height from the finished groundIdentifies work included below the feet

What belongs on the quotation?

Ask a supplier in China to identify the workshop’s scope, the proposed casting construction and the finish sample it will supply. Request separate lines for model development, casting, perch, base interface, packing and freight to a named destination. A low estimate for the bird alone can leave a large perch and a separate delivery leg unpriced.

For a repeat order, ask who keeps the approved model and which future uses the artist has authorised. For a single public artwork, have the site team identify who reviews supports and how the bird will be reached for maintenance. Those details belong with the quote before the order is placed.

An example request for a visitor-centre sculpture

“We are planning a perched barn owl above a visitor-centre sign. The attached sketch marks the bird height from its feet, the branch length and the direction visitors approach. Please price cast bronze, a model for approval and the perch as separate items. State the packed size, delivery scope and any dimensions you need from the sign contractor.”

Frequently asked questions

Can I start with one wildlife photograph?

Yes, if you have permission to use it. Name the species, mark one dimension and describe the hidden side. Ask the supplier to return two model views before casting.

How should a supplier describe a bronze owl?

Ask for the actual casting material and construction in writing. For metal casting, ask whether the body is hollow, how it joins the perch and what finish covers it.

What if I want a second owl facing the other way?

Request a separate left- or right-facing model view. Reversing a pose can change how the feet meet the branch and which facial detail a visitor sees.
